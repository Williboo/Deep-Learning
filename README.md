# Deep-Learning

Kunskapskontroll 1 kod:
Denna mapp innehåller Python koden för kunskapskontroll 1 i kursen Deep Learning. 


Projektmapp:
Detta projekt demonstrerar en modern implementering av Retrieval-Augmented Generation (RAG) med hjälp av en AI-agent. Systemet är utformat för att läsa in specifika PDF-dokument och svara på frågor baserat uteslutande på källmaterialet för att minimera risken för hallucinationer.
